# Grok Bot reset alerts

Follow Grok Bot reset news through GitHub Releases. One repository is one topic: every new announcement or confirmation becomes a release you can subscribe to.

## Subscribe with GitHub Releases

For reset notifications: **Watch → Custom → Releases**.

Sign in to GitHub and watch Releases. We publish one release per meaningful announcement or confirmation; README edits do not send alerts.

[Read published alerts](https://github.com/inmve/grok-reset-alerts/releases)
